# 第一列功能归类清单（Function Type Catalog）

基于仓库 `preview/NP1PP.list` + `preview/C1Y.list`（合并唯一 1260 个 cell）生成。

## 命名规律（结合本库 + 业界惯例）

本库接近 TSMC 类缩写风格，整体可理解为：

```text
[功能根 FunctionRoot][驱动 D<n> 或 X<n>][版图/工艺后缀…]COT[后缀…]
```

| 部分 | 含义 | 例子 | 是否进入第一列功能归类 |
|------|------|------|------------------------|
| 功能根 | 逻辑种类；字母 + 输入个数/结构数字 | `XOR2`, `ND2`(NAND2), `AOI21` | **是** |
| 驱动 | 负载能力 | `D1`/`D10`/`D20`，或 C1Y 的 `X10` | **否**（`XOR2D10` 与 `XOR2D20` 同属 `XOR2`） |
| 优化/工艺后缀 | OPT*/EEQMBD/MDB/VIA/SK*/APA… | `EEQMBD`, `OPTPA`, `AR2` | **否**（先用现有 filter/replace 清掉） |
| `COT…` 及之后 | 库后缀 | `COT`, `COTC`, `COTMDB` | **否**（`COT.*`） |

缩写对照（本库常见）：`ND`=NAND，`NR`=NOR，`AN`=AND，`XNR`=XNOR，`INV`=反相器，`BUFF`/`BUF`=缓冲，`CK*`=时钟版，`G*`=多半为另一阈值/轨高变体。

## 推荐抽取规则（保证覆盖）

1. 先按现有管线清洗全名：`--format-filter '"COT.*" "EEQMBD" "EEQMBC" "OPT" "A.{2}$"'` + `--format-replace '"X(\d{1,2}) : D\1"'`
2. 再取**最后一个**驱动段 `D\d+(?:P\d+)?`（如 `D1`/`D10`/`D0P5`）之前的前缀作为功能根（正则贪婪：`^(.*)(D\d+(?:P\d+)?)(.*)$` 的 group1）
3. 若没有驱动段，则整段清洗结果即为功能根（如 `FILL12`、`ANTENNA`、`TAPCELL`）

该规则对当前 1260 个 cell **覆盖率 100%**（每个 cell 恰好落入一个功能根）。

- cell 总数：1260
- 功能根种类：528
- 例：`XOR2D10`/`XOR2D20` → `XOR2`；`XOR3D1` → `XOR3`（不同）

## 使用注意

1. **复合单元**（如 `XOR2AOI22`、`ND2IOA21`、`OAI21ND2`）与基础 `XOR2`/`ND2` **分开**，因为逻辑功能不同。

3. `FILL12`/`DCAP10` 等数字多为**几何尺寸**而非输入个数；若你也想忽略尺寸，可再归并为 `FILL`/`DCAP`（需另定规则）。
